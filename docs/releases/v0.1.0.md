# LabelLedger v0.1.0

The first working release of a Python/Django dataset review platform.

## Included

- CSV/JSONL imports with validation, content deduplication, and atomic rollback.
- Dataset roles, bounded reviewer assignments, and independent label submission.
- Version conflict detection, manager adjudication, and audit history.
- Unanimous agreement, pairwise agreement, and Fleiss' kappa.
- Responsive interface, JSON API, and decision exports.
- Python wheel/source distribution, container image with PostgreSQL support, and checksums.
- Render deployment configuration with HTTPS, a database health check, and private administrator bootstrap.

## Install and run

Follow the repository README for a local virtual environment and database setup. The container reference and immutable digest are in `container-image.txt`. Release checksums cover the downloaded distributions and container reference.

## Limits

This is an initial release for local or trusted-team use. Imports are synchronous and metrics scan a dataset's votes. Login rate limiting must be provided by the hosting perimeter. Audit events are not cryptographically tamper-evident. The provided free Render database plan expires 30 days after creation; choose a suitable long-term database before storing important data.

No demo credentials or real datasets are included in published artifacts. The local seed command generates its own synthetic examples and passwords.
